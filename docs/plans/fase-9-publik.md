## Exact values
- **Public visibility (one rule, `RealisasiPublik::basis()`):** an SPT is public when all hold: its klasifikasi has `tampil_publik = true` (REGULER by default; the PRD §9.4 column already in `klasifikasi`, so the rule follows Admin's Klasifikasi & Aturan — record it), `status_pengajuan = diterima`, `ditandai_selesai_pada` not null (Selesai), `pkpt_item_id` not null, and that item's PKPT has status Disahkan (an SPT never points the public at an unpublished plan — record it). Every public count, chart, table row and Jadwal progress uses this base.
- **Basis date** (year, TW, month of a public SPT): the `Triwulan` basis date (`rekap.dasar_triwulan`, `tanggal_lhp` falling back to `tanggal_selesai`), in SQL. Add to `Triwulan` the SQL expression it already uses in `batasi()` (e.g. `kolomDasar(): string`) so both share it; SPT without a basis date are excluded. PKPT items use `Triwulan::tanggalDasarItem()`.
- **Wilayah label of an SPT:** from `spt_objek` → `objek`: kecamatan/dinas_badan/bumd/rsud objects by their own name; desa/sekolah/puskesmas/bumdes rolled up to their parent kecamatan's name; distinct, sorted, joined with `, `. When `publik.tampilkan_nama_objek` is true, the objects' own names are shown instead (all levels). Wilayah of a PKPT item (Jadwal) = the rolled-up labels of all `diterima` SPT linked to the item (any status after acceptance, kecamatan level only regardless of the setting); none → `Belum ditentukan`.
- **`App\Services\Publik\RealisasiPublik`** (filter array keys: `tahun` int, `tw` 1–4|null, `bulan` 1–12|null, `irban` id|null, `wilayah` kecamatan objek id|null, `jenis` id|null; `wilayah` matches an SPT whose objects include that kecamatan or one of its children). Methods, all SQL aggregates (GROUP BY), returning plain arrays:
  - `ringkasan(array $f): array{selesai:int, item:int, rencana:int, persen:?float}` — `item` = number of items of the year's Disahkan PKPT (irban/jenis filters applied), `rencana` = their sum of `target_spt` (null = 1; TW filter applied by `tanggalDasarItem`; bulan/wilayah not applicable), `persen` = `round(selesai / rencana * 100, 1)` or null when rencana = 0.
  - `perBulan(array $f, bool $perIrban): array` — 12 counts Jan–Des (or one series of 12 per irban, all irban listed even when 0).
  - `proporsi(array $f, string $menurut /* irban|jenis */): array` — slices sorted descending, at most 6, the rest summed into `Lainnya` (only when > 0); each with `label`, `jumlah`, `persen` (1 decimal), `warna` for jenis (`jenis_penugasan.warna`) / irban index for irban.
  - `rencanaVsRealisasi(array $f, ?int $tw): array` — one row per irban (all irban, ordered by name): `irban`, `rencana`, `realisasi`; follows `tahun`, `irban`, `jenis` and the card's own TW (null = Setahun); ignores `bulan` and `wilayah` (the card caption says `Tidak mengikuti filter Bulan dan Wilayah.` when either is active — record it). Same data shape as the Pimpinan chart so `grafikRealisasi` is reused.
  - `tabel(array $f, string $urut /* asc|desc by basis date */, int $halaman): LengthAwarePaginator` of arrays, 25 per page: `jenis` (nama, warna, warna_teks), `irban`, `wilayah`, `tanggal` (`3–21 Maret 2026`, `28 Februari – 3 Maret 2026`, or across years full dates), `triwulan` (`TW I`…), plus `nomor` only when `publik.tampilkan_nomor_spt`.
  - `opsi(): array` — `tahun` (years with a Disahkan PKPT, desc; default = current Jakarta year when present, else the latest; none → current year with empty states), `irban` (id, nama), `wilayah` (kecamatan objects id, nama), `jenis` (id, nama, warna, warna_teks).
  - Indexes (new migration): `spt (status_pengajuan, klasifikasi_id, pkpt_item_id)` and `spt_objek (objek_id)`; record a measured page time for `/realisasi` and `/jadwal` with a 5.000-SPT factory set (`microtime` in a test or tinker; PRD §10 target < 2 s; caching is Fase 11).
- **`App\Services\Publik\JadwalPublik`:**
  - `item(int $tahun, ?int $irban): array` — items of the year's Disahkan PKPT (none → empty): `id`, `jenis` (id, nama, warna, warna_teks), `irban`, `mulai`, `selesai` (effective, `KesesuaianPkpt::rentang`), `semula` (`[mulai, selesai]` of the original schedule when an approved revision exists, else null), `wilayah` (label rule above), `selesaiSpt` (public SPT count of the item), `target` (`target_spt` ?? 1). Ordered by jenis name, then effective start, then id.
  - `linimasa(array $item, int $tahun): array` — rows per jenis (only jenis with items) each with lanes: greedy lane packing by effective start (an item goes in the first lane whose last bar ends before it starts, comparing grid columns). Grid column of a date = `(bulan - 1) * 5 + min(5, ceil(hari / 7))` (1–60); a bar spans its start column to its end column inclusive (clamped to the year). Same mapping for the `semula` outline. `hariIni` column when the year is the current year, else null.
  - `bulanan(array $item, int $tahun): array` — 12 months; an item appears in every month its effective range overlaps: under `Minggu {n}` of its start date in its start month, under `Minggu 1` in later months (record it); month header count = number of distinct items in that month.
  - `wilayah(int $tahun): array` — per irban (all irban, ordered by name): `Kecamatan`, `Dinas/Badan` (dinas_badan + rsud), `BUMD` lists of names from `irban_wilayah` of that year.
