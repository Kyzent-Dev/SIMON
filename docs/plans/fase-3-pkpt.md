## Exact values
- Tables (all with timestamps):
  - `pkpt`: `tahun` unsignedSmallInteger unique, `nomor_sk` string nullable, `tanggal_sk` date nullable, `status` string default `draf` (enum `App\Enums\StatusPkpt`: `Draf='draf'` label `Draf`, `Disahkan='disahkan'` label `Disahkan`), `disahkan_pada` timestamp nullable, `disahkan_oleh` FK users nullable nullOnDelete.
  - `pkpt_item`: `pkpt_id` FK cascade, `irban_id` FK restrict, `jenis_penugasan_id` FK restrict, `tanggal_mulai` date, `tanggal_selesai` date, `keterangan` string(255) nullable, `target_spt` unsignedSmallInteger nullable; index(`pkpt_id`,`irban_id`).
  - `pkpt_item_revisi`: `pkpt_item_id` FK cascade, `tanggal_mulai_semula` date, `tanggal_selesai_semula` date (snapshot of the effective range at submit time), `tanggal_mulai` date, `tanggal_selesai` date (proposed), `alasan` text, `status` string default `menunggu` (enum `App\Enums\StatusRevisi`: `Menunggu='menunggu'` label `Menunggu Persetujuan`, `Disetujui='disetujui'` label `Disetujui`, `Ditolak='ditolak'` label `Ditolak`), `diajukan_oleh` FK users restrict, `diinput_oleh` FK pegawai nullable restrict, `diputuskan_oleh` FK users nullable nullOnDelete, `diputuskan_pada` timestamp nullable, `komentar` text nullable.
- PKPT rules (`app/Actions/Pkpt/*`, each throws `ValidationException`):
  - Year: `tahun` integer between 2000 and current year + 1; one PKPT per year (`PKPT tahun :tahun sudah ada.`).
  - Only a Draf PKPT can be edited, have items added/changed/deleted/imported, or be deleted: otherwise `PKPT yang sudah disahkan tidak dapat diubah.`
  - Item: irban and jenis penugasan required and existing; `tanggal_mulai` ≤ `tanggal_selesai` (`Tanggal selesai tidak boleh sebelum tanggal mulai.`); both dates inside the PKPT year (`Tanggal harus berada di tahun :tahun.`); `keterangan` max 255; `target_spt` nullable integer 1–999.
  - Sahkan (`SahkanPkpt`): requires `nomor_sk`, `tanggal_sk` (`Isi nomor dan tanggal SK Bupati sebelum mengesahkan.`) and ≥1 item (`PKPT belum memiliki item.`); sets status Disahkan, `disahkan_pada` now, `disahkan_oleh`; irreversible (no "batalkan pengesahan").
  - Delete PKPT only when Draf; delete cascades its items.
  - `Irban::isReferenced()` and `JenisPenugasan::isReferenced()` also return true when a `pkpt_item` references them.
- Effective range and kesesuaian (`App\Services\KesesuaianPkpt`):
  - `rentang(PkptItem): array{0: CarbonImmutable, 1: CarbonImmutable}` = dates of the latest `disetujui` revision (by `diputuskan_pada`, then `id`), else the item's own `tanggal_mulai`/`tanggal_selesai`. The item's own columns are never changed by a revision.
  - `sesuai(PkptItem, $mulai, $selesai): bool` = `rentang.mulai ≤ mulai` and `selesai ≤ rentang.selesai` (inclusive, date-only). Fase 5 uses this for the Tidak Sesuai PKPT flag.
  - `PkptItem::revisiDisetujuiTerakhir()` helper / relation for display ("Jadwal direvisi: semula 3–21 Februari 2026").
- Revision rules:
  - `AjukanRevisiJadwal(User $user, PkptItem $item, array $data)`: authorized by policy `create`; PKPT must be Disahkan (`Revisi hanya untuk PKPT yang sudah disahkan.`); no other `menunggu` revision on the item (`Item ini masih punya revisi yang menunggu persetujuan.`), checked under `lockForUpdate` on the item row inside a transaction; new dates required, `tanggal_mulai` ≤ `tanggal_selesai`, inside the PKPT year, and different from the current effective range (`Tanggal baru sama dengan jadwal yang berlaku.`); `alasan` required, max 1000 (`Isi alasan revisi.`); `diinput_oleh` required for Irban accounts (`Pilih nama penginput terlebih dahulu`) and must be an active pegawai who is PPJ or anggota of that irban's `irban_tahunan` for the current year. Snapshot `*_semula` = `KesesuaianPkpt::rentang($item)` at submit.
  - `PutuskanRevisiJadwal(User $user, PkptItemRevisi $revisi, bool $setujui, ?string $komentar)`: policy `decide`; locks the revision row; only `menunggu` can be decided (`Revisi ini sudah diputuskan.`); Tolak requires `komentar` (`Alasan penolakan wajib diisi.`), Setujui allows an optional komentar; sets status, `diputuskan_oleh`, `diputuskan_pada`.
- `x-app.diinput-oleh` (login.md §5): label "Diinput oleh" + `user-circle` icon, required combobox of the irban's active PPJ+anggota for the current year ("Budi Santoso · …0012"), helper "Pilih pegawai yang benar-benar melakukan input ini.", error "Pilih nama penginput terlebih dahulu"; after a successful write the choice is stored in the session key `diinput_oleh.{irban_id}` and prefilled next time as a mint-50 chip with "Ganti" (button name "Ganti penginput, saat ini Budi Santoso"). Confirm button text "Ajukan sebagai Budi Santoso". Rendered only for Irban accounts.
- Import (template headers exactly): `irban`, `jenis_penugasan`, `tanggal_mulai`, `tanggal_selesai`, `keterangan`, `target_spt`. `irban` matches `irban.nama` or `irban.kode_nomor` (case-insensitive, trimmed); `jenis_penugasan` matches `jenis_penugasan.nama` (case-insensitive, trimmed); dates accept an Excel date serial, `dd/mm/yyyy` or `yyyy-mm-dd`. Messages prefixed `Baris N: ` (N = Excel row number, header = row 1), e.g. `Baris 5: Irban "Irban VI" tidak ditemukan.`, `Baris 7: Jenis penugasan "Reviu X" tidak ditemukan.`, `Baris 9: Format tanggal tidak dikenali (gunakan dd/mm/yyyy).`, plus the item rule messages above. Exact duplicate row (same irban, jenis, dates) already in the PKPT or earlier in the file = warning `Baris N: Item yang sama sudah ada.` (imported only if "Lewati duplikat" is unchecked — default checked → skipped). Max 2000 rows. Import appends to a Draf PKPT inside one transaction.
- Routes: `/admin/pkpt` `admin.pkpt` (list per year); `/admin/pkpt/{pkpt}` `admin.pkpt.show` (item editor); `/admin/pkpt/{pkpt}/impor` `admin.pkpt.impor`; `/irban/pkpt` `irban.pkpt`; `/pimpinan/revisi-jadwal` `pimpinan.revisi-jadwal`.
- Navigation: Irban gets item "Jadwal PKPT" (`irban.pkpt`, icon `calendar-days`); Pimpinan gets "Revisi Jadwal" (`pimpinan.revisi-jadwal`, icon `arrow-path`). Admin's existing `admin.pkpt` item appears automatically once the route exists.
- Tags: PKPT Disahkan = rectangular `rounded` tag mint-100 bg / mint-800 text with `check-badge` icon + "Disahkan"; Draf = neutral-100 / neutral-900 with `pencil-square` + "Draf". Revision states as rectangular tags with icon + label: Menunggu Persetujuan (`clock`), Disetujui (`check`), Ditolak (`x-circle`), using only §3.4 pairs. One component `x-app.tag` (props: `icon`, `variant`).
- Dev seeder `PkptSeeder` (non-production only, after `JenisPenugasanSeeder`/`IrbanSeeder`): current year PKPT Disahkan (nomor SK `100.3.3.2/123/KPTS/INSPEKTORAT/{tahun}`, tanggal SK 2 January), ≥2 items per irban for Irban I and II spread over the year; next year PKPT Draf with 2 items.
