- Known pitfalls (from `docs/plans/serah-terima.md`, each cost a fix round before):
  - **Focus after action:** when a modal closes and its trigger disappears or becomes disabled, move focus to a stable target (heading or `tabindex="-1"` element) via an event dispatched from the component; never let focus fall to `body`.
  - **`sr-only` inside scroll containers:** cells/wrappers holding `sr-only` spans inside `overflow-x-auto` must be `relative`, or the page widens at 360px. Check `document.documentElement.scrollWidth <= 360` with disclosures/details open.
  - **"Diinput oleh"** always in the form/modal footer (login.md §5), never in the body.
  - **Business rules are not recomputed in components**: the action/service exposes a non-throwing method used by both UI and validation (e.g. `ValidatePersonel::cek()`, `Tanggal::durasiPenugasan()`).
  - **Non-field errors:** `ValidationException` keys with no field in the form are shown as a toast, never silently dropped.
  - **Id lookups always scoped** to the user's irban / the SPT, including preview/warning methods, not just save actions.
  - **Timezone:** date/time columns are stored in Jakarta time (APP_TIMEZONE); never `->utc()` when comparing.
  - **xlsx export:** use `App\Exports\ArrayExport`; no new exporter without that binder.
  - **Carbon:** `parse('')` returns "now"; reject empty values before parsing.
  - **Livewire:** a method name must not equal a public property name; ids the client must not change get `#[Locked]`; authorize in `mount()` and every action (the update endpoint skips route middleware).
  - **Factories with `unique()` years** can collide with explicit years in tests; use a range outside the years the test writes.
  - **Numbering:** `Penomoran::ambil` only inside `DB::transaction(..., attempts: 3)` and always with the klasifikasi.
  - **Git staging:** stage files one by one; never `.claude/`, `.playwright/`, `graphify-out/`, `.superpowers/`.
